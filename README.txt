BY SOPHIA FLORAL DESIGN — WEBSITE PREVIEW

Open index.html to preview the homepage. Click an event collection for its dedicated gallery. For best results, run a local server (python3 -m http.server 8765) in this folder and visit http://localhost:8765.

The website includes your supplied photography, updated logo artwork, branding, favicon, and five event galleries. No original uploaded videos are included; a few frames from the videos are included as photos in the Carlos birthday gallery.

FONT NOTE: This edition deliberately mixes Bodoni Moda (major statements), Alice (editorial titles), Cormorant Garamond italics (romantic accents) and DM Sans (everyday text). These load from Google Fonts with built-in browser fallbacks. Your original Tan Pearl-inspired wordmark is already integrated as a logo image. No font files are distributed in this package.

INQUIRY NOTE: The enquiry form prepares an email draft in the visitor’s email app; it does not automatically send an email or save submitted data.

Event dates are intentionally omitted. Projects are separate: That’s Amore, Celebrating Pelusa, A Milestone in Bloom, A Blooming Easter, and Spring, Unscripted.

This is a local website preview; uploading or replacing the existing published site is a separate step.
